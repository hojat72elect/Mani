# Mani - Media Gallery App

A clean, modern cross-platform gallery app built with [Expo](https://expo.dev/) and [React Native](https://reactnative.dev/) technologies. Browse your device's visual media (photos and videos).

## Overview

It organizes photos and videos into folders (albums), lets you filter by media type, and provides a polished fullscreen viewer with swipe navigation.

### Key Features

- **Folders**: categorizes the media by albums (Camera, Screenshots, Downloads, etc).
- **Smart filtering**: Switch between All, Photos only, or Videos only.
- **Fullscreen viewer**: Swipe through media with smooth transitions.
- **Media details**: View resolution, date, file info.
- **Share & delete**: Built-in sharing and deletion of the media
- **Dark/Light theme**: Adapts to system preferences.
- **Pagination**: Efficiently handles large media libraries

## Tech Stack

- **React Native** (0.88.1) with **Expo** (~58.0.23)
- **TypeScript** for type safety
- **expo-media-library** for device media access
- **expo-router** for file-based navigation
- **expo-symbols** for native-feeling icons
- **expo-image** for optimized image loading
